01

问题背景

给定一个 Merkle root 承诺，如何证明承诺的消息是多线性多项式 \(f\)，且 \(f(\mathbf{u}) = v\)？

Basefold 将这个证明拆分为两个子问题：IOPP 证明承诺的消息确实是一个多线性多项式；MLE 求值证明 证明该多项式在打开点 \(\mathbf{u}\) 处的求值等于 \(v\)。两者结合，即可完成求值证明。

下面通过一个完整的数值例子走一遍 Basefold 的全过程。

02

Basefold IOPP

给定一个 Merkle root 承诺，如何证明承诺的消息确实是一个多线性多项式的码字？IOPP（Interactive Oracle Proof of Proximity）通过承诺链和随机抽查来解决这个问题。

IOPP 协议分为两个阶段：承诺阶段中，Prover 将多项式逐轮折叠并承诺；查询阶段中，Verifier 随机抽查若干位置，验证相邻两层的折叠关系是否一致。

2.1

承诺阶段

承诺阶段由三个操作反复循环组成：编码（encode）、承诺（commit）、折叠（fold）——直到消息被折到长度为 1 为止。每一轮的流程如下：

  1. 编码：将当前长度为 \(N\) 的消息向量视为单变量多项式的系数，在求值域 \(D\) 上做 RS 编码（FFT），得到长度为 \(M = N \cdot k\) 的码字，其中 \(k\) 为膨胀系数。
  2. 承诺：对码字做 bit-reverse 排列后，将相邻两个元素两两配对作为 Merkle 树的叶子节点，逐层哈希直到得到根节点，将树根发送给 Verifier。
  3. 折叠：Prover 用随机挑战 \(r\) 将消息向量对半折叠，长度缩减为 \(N/2\)；同时求值域 \(D\) 也对半缩小。

重复以上步骤 \(\log_2 N\) 轮，最终 Prover 共发出 \(\log_2 N + 1\) 个 Merkle 根，形成一条承诺链。

2.1.1

编码（Encode）

将长度为 \(N\) 的消息向量视为单变量多项式的系数，在求值域 \(D\) 上做 FFT，得到长度为 \(M = N \cdot k\) 的码字（\(k\) 为膨胀系数）。

例子：取 \(N = 4\)、\(k=2\)、\(M = 8\)、有限域 \(\mathbb{F}_{17}\)。取 \(M\) 阶乘法子群作为求值域，其生成元为 \(g = 9\)，即 \( D_a = \{g^0,\ g^1,\ \dots,\ g^7\} = \{1,\ 9,\ 13,\ 15,\ 16,\ 8,\ 4,\ 2\} \)。消息向量 \(\mathbf{a} = (2, 3, 5, 7)\) 被视为单变量多项式 \(f(x) = 2 + 3x + 5x^2 + 7x^3\) 的系数，在 \(D_a\) 上做 RS 编码得到长度为 8 的码字，其中 \(u_i = f(g^i)\)，即 \(\mathbf{u} = (0, 12, 13, 11, 14, 3, 15, 16)\)。

2.1.2

承诺（Commit）

得到码字后，Prover 需要将其承诺给 Verifier。承诺的方式是构建一棵 Merkle 树：将码字按 bit-reverse 顺序排列后，相邻两个元素配对作为叶子节点，逐层哈希直到得到根节点。

例子：码字 \(\mathbf{u} = (u_0, u_1, \dots, u_7)\) 共 8 个元素，对其做 BitReversed 排列后得到 \((u_0, u_4, u_2, u_6, u_1, u_5, u_3, u_7)\)，再将相邻两个元素两两配对得到 4 个叶子 \((u_0, u_4)\)、\((u_2, u_6)\)、\((u_1, u_5)\)、\((u_3, u_7)\)。每个叶子哈希后得到 \(h_0, h_1, h_2, h_3\)，不断两两哈希最终得到根节点 \(\text{root}_u\)。

2.1.3

折叠（Fold）

Verifier 发送随机挑战 \(r\)，Prover 用 \(r\) 将消息折叠：由于消息向量是单变量多项式的系数，将其按下标奇偶分为偶次项系数 \(\mathbf{a_E}\) 和奇次项系数 \(\mathbf{a_O}\)，进行线性组合 \(\mathbf{b} = \mathbf{a_E} + r \cdot \mathbf{a_O}\)，长度缩减为 \(N/2\)。与此同时，取 \(D_a\) 中指数为偶数的元素构成新的乘法子群 \(D_b\)。

码字 \(\mathbf{u}\) 与 \(\mathbf{v}\) 之间也存在确定的折叠关系：\(\mathbf{u}\) 的前半部分 \(u_j\) 与后半部分 \(u_{j+M/2}\) 通过下列公式直接计算出 \(v_j\)，其中 \(g\) 为 \(D_a\) 的生成元，\(M = |D_a|\)，\(j = 0, 1, \dots, M/2 - 1\)。

\[v_j = \left(\frac{1}{2} + \frac{r}{2g^j}\right) \cdot u_j + \left(\frac{1}{2} - \frac{r}{2g^j}\right) \cdot u_{j+M/2}\]

例子：消息向量 \(\mathbf{a} = (2, 3, 5, 7)\) 按下标奇偶分为 \(\mathbf{a_E} = (2, 5)\) 和 \(\mathbf{a_O} = (3, 7)\)，取 \(r = 5\)，折叠后 \(\mathbf{b} = \mathbf{a_E} + r \cdot \mathbf{a_O} = (2 + 5 \cdot 3,\ 5 + 5 \cdot 7) = (0, 6)\)。

不妨验证：折叠后的消息 \(\mathbf{b} = (0, 6)\) 编码后得到码字 \(\mathbf{v} = (v_0, v_1, v_2, v_3) = (6, 10, 11, 7)\)（自然顺序），它与原码字 \(\mathbf{u}\) 恰好满足前面的码字折叠公式。例如取 \(j = 2\)（此时 \(g^2 = 13\)，\(r / g^2 \equiv 3\)）：

\[v_2 = \left(\frac{1}{2} + \frac{r}{2 g^2}\right) \cdot u_2 + \left(\frac{1}{2} - \frac{r}{2 g^2}\right) \cdot u_6 = \left(\frac{1}{2} + \frac{3}{2}\right) \cdot 13 + \left(\frac{1}{2} - \frac{3}{2}\right) \cdot 15 \equiv 11 \pmod{17}\]

与编码得到的 \(v_2 = 11\) 一致。这说明无论"先折叠消息再编码"还是"直接对码字按公式折叠"，得到的码字 \(\mathbf{v}\) 完全相同，IOPP 结构在每一轮保持自洽。

2.1.4

完整例子

第 0 轮：Prover 持有消息向量 \(\mathbf{a} = (2, 3, 5, 7)\)，视为单变量多项式 \(g(x) = 2 + 3x + 5x^2 + 7x^3\) 的系数，在求值域 \(D_a = \{1, 9, 13, 15, 16, 8, 4, 2\}\) 上做 FFT 得到码字 \(\mathbf{u} = (0, 12, 13, 11, 14, 3, 15, 16)\)，再将 \(\mathbf{u}\) 按 BitReversed 排列后做 Merkle 承诺，将根 \(\text{root}_u\) 发送给 Verifier。Verifier 发送随机挑战 \(r = 5\)。
第 1 轮：Prover 用随机数 \(r = 5\) 进行折叠：
  • 消息折叠：\(\mathbf{a_E} = (2, 5)\)，\(\mathbf{a_O} = (3, 7)\)，\(\mathbf{b} = \mathbf{a_E} + r \cdot \mathbf{a_O} = (0, 6)\)
在求值域 \(D_b = \{1, 13, 16, 4\}\) 上做 FFT 得到码字 \(\mathbf{v} = (6, 10, 11, 7)\)，再将 \(\mathbf{v}\) 按 BitReversed 排列后做 Merkle 承诺，将根 \(\text{root}_v\) 发送给 Verifier。Verifier 发送随机挑战 \(s = 3\)。
第 2 轮：Prover 用 \(s = 3\) 继续折叠：
  • 消息折叠：\(b_0 = 0\)，\(b_1 = 6\)，\(c_0 = b_0 + s \cdot b_1 = 0 + 3 \cdot 6 \equiv 1 \pmod{17}\)
在求值域 \(D_c = \{1, 16\}\) 上做 FFT 得到码字 \(\mathbf{w} = (1, 1)\)，再将 \(\mathbf{w}\) 按 BitReversed 排列后做 Merkle 承诺，将根 \(\text{root}_w\) 发送给 Verifier，承诺阶段结束。
2.2

查询阶段

承诺阶段结束后，Verifier 随机选一个位置，从最外层码字开始，逐轮检查相邻两层码字在该位置是否满足折叠关系。重复足够多次后，即可高概率确信 Prover 没有作弊。

假设 Verifier 随机抽到了位置 \(i=3\)，下面逐轮演示检查过程。

第 0 轮→第 1 轮的检查：Prover 发送 \(u_3 = 11\) 和 \(u_7 = 16\)，并提供它们的 Merkle 证明。Verifier 验证 Merkle 证明通过后，利用码字折叠公式计算期望的 \(\hat{v}_3\)，其中基点 \(g^3 = 15\)：
\[\hat{v}_3 = \left(\frac{1}{2} + \frac{r}{2 g^3}\right) \cdot u_3 + \left(\frac{1}{2} - \frac{r}{2 g^3}\right) \cdot u_7 = 12 \cdot 11 + 6 \cdot 16 \equiv 7 \pmod{17}\]
第 1 轮→第 2 轮的检查：Prover 发送 \(v_1 = 10\) 和 \(v_3 = 7\)，并提供它们的 Merkle 证明。Verifier 验证 Merkle 证明后，先检查 \(v_3 = \hat{v}_3 = 7\) ✓，确认第 0 层到第 1 层的折叠一致。然后计算期望的 \(\hat{w}_1\)，基点 \(g^2 = 13\)：
\[\hat{w}_1 = \left(\frac{1}{2} + \frac{s}{2 g^2}\right) \cdot v_1 + \left(\frac{1}{2} - \frac{s}{2 g^2}\right) \cdot v_3 = 15 \cdot 10 + 3 \cdot 7 \equiv 1 \pmod{17}\]
最后一轮的检查：Verifier 使用 \(\hat{w}_1 = 1\) 重构 \(\hat{\text{root}}_w = \text{Hash}(1, 1)\)，与承诺阶段收到的 \(\text{root}_w\) 比对，确认一致即可。✓

重复足够多次查询后，即可高概率确信 Prover 没有作弊。

03

MLE 求值证明

如何证明多线性多项式 \(f(x_1, \dots, x_n)\) 在点 \(\mathbf{u} = (u_1, \dots, u_n)\) 处的求值等于 \(v\)？利用 \(f\) 关于最后一个变量 \(x_n\) 是线性的，有：

\[f(x_1, \dots, x_n) = (1 - x_n)\, f(x_1, \dots, x_{n-1}, 0) + x_n\, f(x_1, \dots, x_{n-1}, 1)\]

Prover 和 Verifier 重复以下过程，每一轮消去一个变量，直到变量数为 0：

  • 发送：把目标点的前 \(n-1\) 个坐标 \(u_1, \dots, u_{n-1}\) 代进去，最后一维分别取 0 和 1，得到两个数 \(o_0 = f(u_1, \dots, u_{n-1}, 0)\) 和 \(o_1 = f(u_1, \dots, u_{n-1}, 1)\)，Prover 把它们发给 Verifier；
  • 验证：Verifier 用上面的恒等式核对 \(v = (1 - u_n)\, o_0 + u_n\, o_1\)，通过后发送随机数 \(r\)；
  • 折叠：把多项式折成新的 \((n-1)\) 元多项式 \(\hat{f} = f(\cdot, 0) + r\, f(\cdot, 1)\)，并令 \(\hat{v} = o_0 + r\, o_1\)。证明目标更新为"\(\hat{f}\) 在 \((u_1, \dots, u_{n-1})\) 处的求值等于 \(\hat{v}\)"。
3.1

完整例子

消息向量 \(\mathbf{a} = (2, 3, 5, 7)\) 视为 \(f\) 在 \(\{0,1\}^2\) 上的求值，即 \(f(0,0)=2,\ f(0,1)=3,\ f(1,0)=5,\ f(1,1)=7\)。Verifier 要验证 \(f\) 在 \(\mathbf{u} = (3, 4)\) 处的求值，Prover 声称 \(v = 10\)：

\[v = f(u_1, u_2) = (1 - u_2)\, f(u_1, 0) + u_2\, f(u_1, 1) = (1 - 4)\cdot 11 + 4\cdot 15 \equiv 10 \pmod{17}\]
第 1 轮 · Prover（消去 \(x_2\)）：Prover 发送 \(o_0 = f(u_1, 0) = 11\) 和 \(o_1 = f(u_1, 1) = 15\)。
第 1 轮 · Verifier：核对 \((1 - u_2)\,o_0 + u_2\,o_1 = (1-4)\cdot 11 + 4\cdot 15 \equiv 10 = v\) ✓。发送随机数 \(r = 5\)，并把新目标更新为 \(\hat{v} = o_0 + r\,o_1 = 11 + 5\cdot 15 \equiv 1\)。
第 2 轮 · Prover（消去 \(x_1\)）：先用 \(r = 5\) 把 \(f\) 折叠成 \(\hat{f}(x) = f(x, 0) + r\,f(x, 1)\)，对应消息向量 \(\mathbf{b} = \mathbf{a}_E + r\,\mathbf{a}_O = (0, 6)\)。再把 \(\hat{f}\) 的 \(x_1\) 代入 0、1，得 \(p_0 = \hat{f}(0) = 0\)、\(p_1 = \hat{f}(1) = 6\)，发送 \(p_0, p_1\)。
第 2 轮 · Verifier：核对 \((1 - u_1)\,p_0 + u_1\,p_1 = (1-3)\cdot 0 + 3\cdot 6 \equiv 1 = \hat{v}\) ✓。发送随机数 \(s = 3\)，并把新目标更新为 \(\tilde{v} = p_0 + s\,p_1 = 0 + 3\cdot 6 \equiv 1\)。
最终 · Prover：用 \(s = 3\) 把 \(\hat{f}\) 折叠成常数 \(\tilde{f} = p_0 + s\,p_1 = 0 + 3\cdot 6 \equiv 1\)，对应消息向量 \(\mathbf{c} = \mathbf{b}_E + s\,\mathbf{b}_O = (1)\)。现在只需证明 \(\tilde{f} = \tilde{v} = 1\) ✓。而常数 \(\tilde{f}\) 正是最后一轮的常数码字，Verifier 在查询阶段可以自己得到，无需 Prover 额外发送。
3.2

MLE 求值 + IOPP 联动

IOPP 每一轮把消息按下标奇偶折叠：\(\mathbf{b} = \mathbf{a_E} + r\,\mathbf{a_O}\)，长度减半。

MLE 求值证明每一轮把多项式折成 \(\hat{f} = f(\cdot, 0) + r\,f(\cdot, 1)\)，消去最后一个变量；其消息向量同样按下标奇偶折叠 \(\mathbf{b} = \mathbf{a_E} + r\,\mathbf{a_O}\)，长度减半。

两者是同一个折叠运算、用同一个随机数 \(r\)、作用在同一份消息向量上。因此可以合二为一：MLE 求值证明保证求值正确，IOPP 保证多项式真实，两条线在每一轮共享 \(r\) 同步折叠。
